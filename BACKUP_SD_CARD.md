# How to Backup an SD Card

## Quick Start (5 Steps)

```bash
# 1. Mount your SD card
mount /dev/sdX /mnt/sdcard

# 2. Scan it
photo-organizer scan /mnt/sdcard -machine "camera"

# 3. Find what needs backing up
photo-organizer migrate --from camera --dest /backup/nas

# 4. Review the migration script
bash _migrate_camera*.sh

# 5. Eject the SD card safely
umount /mnt/sdcard
```

Done! New photos are backed up. ✓

---

## Detailed Workflow

### Step 1: Mount the SD Card

**macOS**:
```bash
# Usually auto-mounts as /Volumes/SDCARD
ls /Volumes/SDCARD
```

**Linux**:
```bash
sudo mount /dev/sdX /mnt/sdcard
ls /mnt/sdcard
```

**Windows**:
- Insert card → appears in File Explorer

### Step 2: Scan the Card

Use a **machine name that represents the camera**, not the card:

```bash
# Same machine name every time you use this camera
photo-organizer scan /mnt/sdcard -machine "camera"
```

**Why the same machine name?**
- Tool tracks which photos came from the same camera
- Automatically detects if you've imported the same photo before
- Knows which files are new vs. already-on-backup

### Step 3: Check What Needs Backing Up

**Option A: See what's new**
```bash
# Show only files NOT yet on backup
photo-organizer search -machine "camera" -duplicates-only
# If empty: all camera photos already backed up
# If files shown: these need backup
```

**Option B: Compare with backup**
```bash
# Full analysis across all machines
photo-organizer analyze

# Output shows:
# Machines: backup camera
# 
# Camera has 450 files
# Backup has 400 files  
# 50 files only on camera (NEED BACKUP)
```

### Step 4: Generate Backup Script

```bash
# Create rsync script to copy new files to backup
photo-organizer migrate --from camera --dest /backup/nas
```

**Output**:
```
Wrote migration script to /tmp/_migrate_camera_*.sh (50 files, 2.3 GB)
```

### Step 5: Review the Script

```bash
# Check what will be transferred
cat _migrate_camera_*.sh | head -50

# Example output:
# #!/bin/bash
# # Migration script generated by photo-organizer
# # Source machine: camera
# # Destination: /backup/nas
# # Unique files: 50  (2.3 GB)
# ...
# rsync -av --checksum --partial --progress \
#   --files-from="$WORK_DIR/group_1.txt" \
#   '/mnt/sdcard/' '/backup/nas/Photos/'
```

### Step 6: Run the Backup

```bash
# Execute the migration script
bash _migrate_camera_*.sh

# Output:
# Pre-flight checks:
# ✓ Source path /mnt/sdcard readable
# ✓ Destination /backup/nas writable
# ✓ Disk space available
#
# Pre-flight checks passed.
#
# [1/1] Copying 50 files (2.3 GB)...
# sending incremental file list
# Photos/2024-06/IMG_001.jpg
# Photos/2024-06/IMG_002.jpg
# ...
# Migration complete. 1 group(s) transferred.
```

### Step 7: Verify Backup

```bash
# Confirm files are on backup
ls -la /backup/nas/Photos/2024-06/

# Or scan backup to verify
photo-organizer scan /backup/nas -machine "backup"
photo-organizer analyze
# Should show camera files are now also on backup
```

### Step 8: Safe to Reformat Card

Now you know the photos are backed up:

```bash
# Safely eject
umount /mnt/sdcard

# Format the card (in camera or via command line)
# macOS:
diskutil secureErase freespace 0 /Volumes/SDCARD

# Or just use camera menu to format
```

## Complete Real-World Example

### Setup (One-Time)

```bash
# Add backup location to machines config
photo-organizer collect --add backup=lei@nas.local

# Verify
cat ~/manifests/machines.conf
# backup=lei@nas.local
```

### Backup Workflow (Repeat Each Import)

```bash
# 1. Insert card, it auto-mounts
# 2. Scan it
photo-organizer scan /Volumes/SDCARD -machine "canon-eos"

# 3. Check what's new
photo-organizer search -machine "canon-eos" -duplicates-only
# Output: 247 new files found

# 4. Create backup script
photo-organizer migrate --from canon-eos --dest nas:/backup/photos

# 5. Review
head -20 _migrate_canon_eos_*.sh

# 6. Run backup
bash _migrate_canon_eos_*.sh
# Takes 15 minutes for 2.5GB...

# 7. Verify
photo-organizer analyze
# Shows: 247 files now on both canon-eos and nas backup ✓

# 8. Format card
# Eject and format in camera
```

## Different Backup Scenarios

### Scenario 1: Backup to Local External Drive

```bash
# Mount external drive
mount /dev/sdX /mnt/external

# Scan card
photo-organizer scan /mnt/camera -machine "camera"

# Backup to external
photo-organizer migrate --from camera --dest /mnt/external/backup
bash _migrate_camera_*.sh

# Verify
photo-organizer scan /mnt/external/backup -machine "backup"
photo-organizer analyze
```

### Scenario 2: Backup to Network NAS

```bash
# Add NAS to machines config
photo-organizer collect --add nas=lei@192.168.1.100

# Scan card
photo-organizer scan /mnt/camera -machine "camera"

# Backup to NAS (over network)
photo-organizer migrate --from camera --dest nas:/volume1/photos
bash _migrate_camera_*.sh

# This runs rsync over SSH—slower but safe over network
```

### Scenario 3: Multiple Cameras, One Backup

```bash
# Scan Camera 1
photo-organizer scan /mnt/canon -machine "camera-canon"

# Scan Camera 2
photo-organizer scan /mnt/nikon -machine "camera-nikon"

# Backup both to same location
photo-organizer migrate --from camera-canon --dest /backup
bash _migrate_camera_canon_*.sh

photo-organizer migrate --from camera-nikon --dest /backup
bash _migrate_camera_nikon_*.sh

# Verify both backed up
photo-organizer analyze
# Shows both camera manifests, files from both now on backup
```

### Scenario 4: Incremental Backup (Only New Photos)

After you've already backed up once:

```bash
# Card still has old photos + new ones
photo-organizer scan /mnt/camera -machine "camera"

# Tool sees old photos on both camera manifest and backup
# Only migrates truly NEW photos
photo-organizer migrate --from camera --dest /backup
bash _migrate_camera_*.sh
# Only copies photos taken since last backup
```

## Important: Resume Interrupted Backup

If backup fails mid-transfer:

```bash
# Network hiccup? Just run the script again
bash _migrate_camera_*.sh
# Rsync resumes from where it stopped
# Already-transferred files are skipped

# Shows:
# [1/1] Copying 50 files (2.3 GB)...
# ...
# Migration complete. 1 group(s) transferred.
```

**How it works**: 
- Script uses `.done` markers to track progress
- Re-running skips completed groups automatically
- No re-copying, no data loss

## Safety Checklist

Before you format and reuse the card:

- [ ] Backup script completed successfully (`Migration complete`)
- [ ] Verified files on backup: `ls /backup/photos/`
- [ ] Ran `photo-organizer analyze` to confirm backup is recognized
- [ ] At least 2 weeks have passed (give backup time to sync/verify)
- [ ] You've successfully restored from backup in the past (optional but recommended)

## Workflow Variations

### Quick Backup (No Review)
```bash
photo-organizer scan /mnt/camera -machine "camera"
photo-organizer migrate --from camera --dest /backup
bash _migrate_camera_*.sh
```

### Backup with Verification
```bash
photo-organizer scan /mnt/camera -machine "camera"
photo-organizer search -machine "camera" -duplicates-only  # Show what's new
photo-organizer migrate --from camera --dest /backup
head -20 _migrate_camera_*.sh  # Preview
bash _migrate_camera_*.sh
photo-organizer analyze  # Confirm both machines have files
```

### Backup Multiple Destinations
```bash
# Backup to local drive AND network NAS
photo-organizer migrate --from camera --dest /mnt/external
bash _migrate_camera_external_*.sh

photo-organizer migrate --from camera --dest nas:/backup
bash _migrate_camera_nas_*.sh

# Both now tracked
photo-organizer machines
# Shows: backup-external, backup-nas, camera
```

## Troubleshooting

### "Backup script failed—disk full"
```bash
# Free up space on backup destination
df -h /backup
du -sh /backup/*

# Then re-run the script (it resumes)
bash _migrate_camera_*.sh
```

### "How do I know if backup succeeded?"
```bash
# Check the backup location
ls -la /backup/photos/  # See the files

# Verify via photo-organizer
photo-organizer scan /backup -machine "backup"
photo-organizer analyze
# Should show camera files also on backup machine
```

### "Card still has old photos even after backup"
```bash
# This is normal! Backup copies, doesn't delete.
# Now safe to format:

# macOS
diskutil secureErase freespace 0 /Volumes/SDCARD

# Linux
sudo shred -vfz -n 3 /mnt/sdcard/*
```

### "Backup was interrupted—how to resume?"
```bash
# Check which files were already copied
ls /backup/photos/2024-06/

# Re-run the script—it skips already-copied files
bash _migrate_camera_*.sh

# Progress resumes from checkpoint
```

## Best Practices

✅ **Use same machine name** — Track the same camera consistently  
✅ **Backup before reformatting** — Always verify backup first  
✅ **Keep both backups** — One backup is no backup (have 2 copies)  
✅ **Test restore** — Once a year, restore from backup to verify it works  
✅ **Document strategy** — Keep machines.conf as your reference  
✅ **Review script** — Always preview before running large transfers

## Recommended Backup Strategy

### 3-2-1 Backup Rule
- **3 copies**: Camera + Backup1 + Backup2
- **2 types**: Local NAS + External USB
- **1 offsite**: Optional cloud (Dropbox, Google Drive)

```bash
# Setup
photo-organizer collect --add camera=lei@camera
photo-organizer collect --add nas-backup=lei@nas
photo-organizer collect --add usb-backup=lei@usb-drive

# Scan camera
photo-organizer scan /mnt/camera -machine "camera"

# Backup to both locations
photo-organizer migrate --from camera --dest nas:/photos
bash _migrate_camera_nas_*.sh

photo-organizer migrate --from camera --dest /mnt/usb/backup
bash _migrate_camera_usb_*.sh

# Now you have 3 copies: camera + 2 backups
photo-organizer analyze
```
